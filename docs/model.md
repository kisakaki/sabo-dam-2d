# 計算方法

## 流れ

- 平面2次元浅水流方程式（保存形）を、セル中心の有限体積法で解く。
- 数値流束は HLL 近似リーマン解法。地形の段差は静水圧再構築（Audusse ら 2004、Chen・Noelle 2017）で扱い、静水が保たれる。
- 水深 h と水位 η を minmod 制限付きで区分線形に再構築（2 次精度）。時間積分は陽的 Euler、Δt は CFL 条件（0.4）。
- 摩擦は Manning 則を半陰的に入れる。
- 境界：上流端は流量を水深の 5/3 乗で重み付けして横断方向に配分。下流端は自由流出。側方は壁。
- 計算の前に、水だけを流して流れを立ち上げる（助走計算）。

## 流砂と河床変動

既定では、侵食と堆積は粒径ごとの掃流砂量の収支（Exner 式）から決まる（平衡流砂）。浮遊砂は扱わない。

1. 摩擦速度 u*² = g n² V² / h^(1/3)。有効摩擦速度は芦田・道上の対数則 u*e = V / {6 + 5.75 log10(h / (dm(1+2τ*m)))}（u* を上限）。
2. 限界掃流力（平均粒径）
   - 芦田・高橋・水山（1978）式(24)：τ*cm = 0.04 × 10^(1.72 i)。i は流れの向きの河床勾配（0〜0.2）。
   - 岩垣式（1956）、一定値も選べる。
   - 粒径別は修正 Egiazaroff 式（既定）か、u*ci = u*cm（芦田・高橋・水山の結果）。
   - 注意：芦田・道上式では粒径 d_i が式の中で消えるため、粒径による違い（選択的な流出）は u*ci だけから生まれる。u*ci = u*cm を選ぶと全粒径が同じ割合で動き、表層の粒度は変わらない。
3. 粒径別の掃流砂量（芦田・道上式、1972）
   q_bi = 17 p_i u*e³ / {(σ/ρ−1) g} × (1 − u*ci²/u*²)(1 − u*ci/u*)
4. 向きは流速方向。河床勾配による重力の効果（長谷川 1981 型）q_b = q_b(流速方向) − ε q_b ∇z、ε = √(τ*c/τ*)/√(μs μk)（μs = 1.0、μk = 0.45）。格子規模の凹凸を抑えるため ε に下限 0.3 Δx/h を設ける（数値上の工夫）。
5. Exner 式 (1−λ) ∂V_i/∂t + ∇·q_bi = 0 を粒径ごとに解く（風上差分、交換層の量を超えて持ち出さない制限付き）。
6. 交換層（平野 1971、厚さは既定で最大粒径）＋多層の堆積層（1 層 0.25 m）。堆積はそのときの粒度で積み、侵食は下の層の粒度で補う。
7. 侵食は「侵食可能深」（既定 3 m）まで。谷壁と堰堤は固定床。
8. 安息角を超える斜面は、超えた分の 1/4 ずつ低い側へ崩す。水に浸かった斜面は水中の安息角（既定 30°、高橋・里深・奥村 1996）、乾いた斜面は陸上の安息角（既定 50°）で判定する（XBeach の wetslp／dryslp と同じ考え方）。
9. 給砂は上流端で Qs = Cs × Q（粒度は「供給土砂の割合」）。
10. 河床変動の加速係数（既定 4）で、河床変動と出水の時刻を流れより速く進める。

## 非平衡の流砂（選択）

「流砂量の求め方」を「侵食・堆積速度式」にすると、高橋・里深（1999）、高橋ら（1998）の式で計算する。

- 侵食（C∞ > C、u* > u*ck）：i_k = f_bk δe (C∞ − C)/C* |u* − u*ck|
- 堆積（C∞ ≤ C、u* < u*ck）：i_k = f_0k δd (C∞ − C)/C* |u* − u*ck|
- C∞ = Σ f_bk q_bu,k / q（q_bu,k は粒径 k だけのときの芦田・道上式）。u* = V / {6 + 5.75 log10(h/ks)}、ks は表層の d90。
- 流れの中の粒径別土砂 C_k h を ∂(C_k h)/∂t + ∇·(C_k h u') = C* i_k で運び、∂z/∂t = −Σ i_k。u' は横断勾配による重力の効果で向きを補正した流速（長谷川型）。
- 既定 δe = δd = 0.6。水際（水深が平均粒径の 2.5 倍未満）では δe を 2 倍、δd を 10 倍にする（高橋・里深 1999 は水深 5 mm 以下で 1.2、6.0）。
- 水が引いたセルでは、流れの中の土砂をその場に堆積させる。

## 側岸侵食（選択）

- **侵食できる側岸**：谷壁のうち、谷底から「側岸として侵食できる高さ」までを段丘・崖錐の土砂とし、侵食と崩落の対象にする。
- **水際の乾いた側岸の侵食**：濡れたセルが侵食されたとき、その量の一定割合を隣の乾いた（より高い）側岸セルから削り、濡れたセルに移す（Delft3D の dry-cell erosion、THETSD と同じ考え方）。
- **巨礫による流路の固定**：初期の水みち（なければ谷底）の両岸に、動かない巨礫を間隔 L で置く（向かい合わせか千鳥）。巨礫のセルは侵食も堆積もしない。高橋・里深・奥村（1996）の実験では L ≤ 9B/4（B は水みち幅）で拡幅・分裂が抑えられた。
- 検討用の例（幅 10 m、勾配 1/40、25 m³/s を 30 分）：側岸固定で水面幅 12.0 m、侵食できる高さ 2 m で 14.0 m（側岸の侵食 633 m³）。土砂収支は丸め誤差の範囲で閉じる。
- **長谷川の崩落モデル（選択。長谷川 1983、長田ら 1996 式17）**：乾いた側岸セルの隣が水に浸かっているとき、側岸の位置の水面から水中安息角 βk で下る線を引く。横断方向（4 方向）に、線より上の土塊 A（側岸セルの水面より上の部分と、続く斜面の線より上の部分）と、線より下の洗掘の不足 B を数え、B ≥ A になったら A を一度に崩して B を比例配分で埋め戻す。式17 の ΔBc（崩落限界幅）は 1 セル。この方式では、水際の乾いた側岸は安息角による崩落の対象から外す（根元の洗掘が溜まるまで立っている）。
- 橋本ら（2003）の急勾配裸地の侵食速度式 ∂z/∂t = kc CT² v は、側岸侵食の式ではないため使っていない。

## 湾曲部の2次流（選択。長田ら 1996）

- 流線の曲率 κ = 1/r = {u(u v_x + v v_y) − v(u u_x + v u_y)}/V³（左曲がりが正）。流速は面の流束の平均、濡れたセルで 3×3 平均を 2 回とる。|h κ| は hrMax（既定 0.05）で頭打ち。
- **流砂の向き**（式11・14）：河床付近の流速の横断成分 u_nb/u_sb = N* h/r（N* = 11.5）を、長谷川式の横断方向流砂 q_Bn = q_Bs (u_nb/u_sb − √(τ*c/(μs μk τ*)) ∂z/∂n) に加える。平衡流砂量ではセルの流砂ベクトルを、非平衡の計算では輸送速度の向きを回す。
- **運動量の分散項**（式19〜23、Kalkwijk・de Vriend 1980）：s–n 座標の T_sn = −k_sn h² V² κ（主流の運動量を外岸へ運ぶ）を x–y に回して運動方程式に加える。Txx = −Tyy = 2 k_sn h² κ u v、Txy = −k_sn h² κ (u² − v²)、k_sn = 5a − 15.6a² + 37.5a³、a = √g/(κ_K C)（C = h^(1/6)/n、a ≤ 0.4）。面の値は両側のセルの平均（どちらかが乾いていれば 0）で、保存形で加える。
- 確認（蛇行水路、幅 12 m、勾配 1/100、20 m³/s を 30 分）：流砂の向きを入れると外岸が内岸より 0.4〜0.7 m 深く掘れ、分散項を入れると流速最大の位置が外岸側へ 4〜5 m 寄る（入れないと内岸側に寄る）。長田らの Fig. 9 と同じ傾向。

## 堰堤

- 1 セル幅の固定床として置く。水通しの天端・袖の天端を標高で与える。
- 既定では河道の中心線に直角（両岸に直角）。回転角・中心・天端標高・堤長を指定すれば、その値で置く。
- 4 近傍で水が漏れない厚さにしている。

## 透過型堰堤（選択）

形式は 不透過型・スリット（1 本）・複数スリット・鋼製格子型・鋼製スリット型。開口幅 l、開口数 n、部材幅 w を与える。

- 開口のセルは、開口の底（既定は堤の基礎）の高さを固定床とする移動床にする。
- 開口率 φ：鋼製格子型 φ_水 = {l/(l+w)}²、φ_砂 = l/(l+w)。鋼製スリット型 φ = l/(l+w)。スリットは n·l / セル幅（1 以下）。天端より上の流れは損失なし（水深で重み付け）。
- 水の損失：多孔板の損失係数（Idelchik）ζ = {(1 + 0.707√(1−φ) − φ)/φ}²、損失水頭 ζV²/2g を半陰的な抵抗として運動方程式に加える。
- 土砂：開口率 φ_砂 の割合で通過。粒径 d ≥ l/α の礫は通らない（α 既定 1）。
- 閉塞：上流の土砂濃度 C ≥ C_blk（既定 0.2）かつ l ≤ β d95（β 既定 1.5）で閉塞とし、以後は φ を 0.05（既定）に下げる。β は 土石流対策技術指針（案）（2000、β = 1.5）、砂防基本計画策定指針（土石流・流木対策編）解説（2016、β = 1.0 を含む）による。C_blk は本プログラムの仮定。
- 透過型は計算開始時に満砂にしない。

## 土石流の一波（選択）

ハイドロの「波形」を「土石流の一波」にすると、基底流量に三角形の波（到達時刻・立ち上がり・減衰・ピーク流量・土砂濃度）を重ね、上流端から流す。流砂の求め方は自動で「土石流」になり、加速係数は 1。

- Kanako 2D（Nakatani et al. 2008）、高橋（2007）と同じ形の式。混合物の水深 h と土砂濃度 C を運ぶ。
- 侵食：i = δe (C∞ − C)/(C* − C∞) · q/d（δe = 0.0007）。堆積：i = δd (C∞ − C)/C* · V（δd = 0.05、V の下限 0.1 m/s）。
- 平衡濃度 C∞（水面勾配 tanθ）：tanθ > 0.138 で ρ tanθ / {(σ−ρ)(tanφ − tanθ)}（石礫型）、0.03〜0.138 で 6.7 × (同)²（掃流状集合流動）、0.03 以下は掃流砂量式から。上限 0.9C*。
- 侵食・堆積速度式の水面勾配は、流れの下流側の片側差分で求める（中心差分では 1 セルおきの凹凸が残り、堆積面が市松模様になる）。
- 抵抗：C ≥ 0.4C* は石礫型（高橋）、0.01 ≤ C < 0.4C* は乱流型 d²/(0.49h²)、それ以下と下限は Manning。
- 流入する波の水深・流速は「流入点より上流の勾配」での等流（高橋の抵抗則）から決める。
- 侵食で河床が下がるとき、間隙の水は河床から供給される（飽和河床）。
- 適用：土石流・掃流状集合流動の段階。急な地形変化（勾配の変化点での急な堆積、堰堤上流の堆積）を再現する。平衡流砂量の式（芦田・道上）の範囲の現象は、ほかの流砂モデルで計算する方がよい。

## 支川（選択）

支川の合流点（x）・左右・川幅・勾配・流量の比 r・土砂の比 rs・遅れ時間・合流角を与える。合流角は本川と支川の流下方向のなす角（90° で直角、30〜150°）。

- 本川の谷壁から計算領域の端まで、合流角の向きに、支川の勾配で水路を掘り、その周りに V 字の谷（側面 1:2）を付ける。必要なら計算領域を横に広げる。
- 支川の上流端から流入させる（流量 r·Q(t−遅れ)、土砂 rs·Qs(t−遅れ)。土石流では 0.9C*·Q が上限）。運動量は合流角の向きに与える。
- 合流点の勾配が急なら、本川の谷底に沖積錐ができ、本川の流れが対岸へ押される。
- 沖積錐の上での流路の首振りは、試した範囲では起きにくい。土砂を何回かに分けて流す（土石流と水だけの流れを交互に）、合流角を 90° からずらす、格子を細かくする（1 m 程度）、本川の谷底を広くし勾配を緩くする、が効く。土石流の式は流れの中の流路の形成（自己形成的な水路）を直接は扱わないため、首振りの再現性には限界がある。

## 伏流（選択）

- 河床の間隙の水を地下水として扱う。透水係数 k は Kozeny–Carman 式（Carman 1937）k = (g/ν) n³/(1−n)² · d_h²/180、d_h は交換層の調和平均粒径（上限 kMax）。値を直接与えることもできる。
- 浸透：単位動水勾配で k、間隙が満ちるまで。
- 地下水の流れ：Dupuit 近似の Darcy 則（陽的、細かい時間刻み）。間隙を超えた分は地表に湧き出す。下流端から勾配 Ix で流出。
- 地表の流れと地下水を合わせた例として、SiMHiS（山野井・藤田 2017）がある。
- 水の収支（地表＋地下水＋流入出）は丸め誤差の範囲で閉じる。

## 勾配の折れ点

「勾配を途中で変える」の表に [x, 1/n] を並べると、その x から下流の勾配が 1/n になる（何段でも可）。河床は下流端から積み上げて決める。CSV の地形とは別に、数値で指定した地形で使う。

## 扱わないこと

- 浮遊砂・ウォッシュロード
- 流木
- 透過型堰堤の部材の変形・破壊
