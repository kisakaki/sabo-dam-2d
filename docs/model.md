# 計算方法

## 流れ

- 平面2次元浅水流方程式（保存形）を、セル中心の有限体積法で解く。
- 数値流束は HLL 近似リーマン解法。地形の段差は静水圧再構築（Audusse ら 2004、Chen・Noelle 2017）で扱い、静水が保たれる。
- 水深 h と水位 η を minmod 制限付きで区分線形に再構築（2 次精度）。時間積分は陽的 Euler、Δt は CFL 条件（0.4）。
- 摩擦は Manning 則を半陰的に入れる。
- 境界：上流端は流量を水深の 5/3 乗で重み付けして横断方向に配分。下流端は自由流出。側方は壁。
- 計算の前に、水だけを流して流れを立ち上げる（助走計算）。

## 流砂と河床変動

侵食と堆積は、粒径ごとの掃流砂量の収支（Exner 式）から決まる。浮遊砂は扱わない。

1. 摩擦速度 u*² = g n² V² / h^(1/3)。有効摩擦速度は芦田・道上の対数則 u*e = V / {6 + 5.75 log10(h / (dm(1+2τ*m)))}（u* を上限）。
2. 限界掃流力（平均粒径）
   - 芦田・高橋・水山（1978）式(24)：τ*cm = 0.04 × 10^(1.72 i)。i は流れの向きの河床勾配（0〜0.2）。
   - 岩垣式（1956）、一定値も選べる。
   - 粒径別は u*ci = u*cm（芦田・高橋・水山の結果）か、修正 Egiazaroff 式。
3. 粒径別の掃流砂量（芦田・道上式、1972）
   q_bi = 17 p_i u*e³ / {(σ/ρ−1) g} × (1 − u*ci²/u*²)(1 − u*ci/u*)
4. 向きは流速方向。河床勾配による重力の効果（長谷川 1981 型）q_b = q_b(流速方向) − ε q_b ∇z、ε = √(τ*c/τ*)/√(μs μk)（μs = 1.0、μk = 0.45）。格子規模の凹凸を抑えるため ε に下限 0.3 Δx/h を設ける（数値上の工夫）。
5. Exner 式 (1−λ) ∂V_i/∂t + ∇·q_bi = 0 を粒径ごとに解く（風上差分、交換層の量を超えて持ち出さない制限付き）。
6. 交換層（平野 1971、厚さは既定で最大粒径）＋多層の堆積層（1 層 0.25 m）。堆積はそのときの粒度で積み、侵食は下の層の粒度で補う。
7. 侵食は「侵食可能深」（既定 3 m）まで。谷壁と堰堤は固定床。
8. 安息角（既定 35°）を超える斜面は、超えた分の 1/4 ずつ低い側へ崩す。
9. 給砂は上流端で Qs = Cs × Q（粒度は「供給土砂の割合」）。
10. 河床変動の加速係数（既定 4）で、河床変動と出水の時刻を流れより速く進める。

## 堰堤

- 1 セル幅の固定床として置く。水通しの天端・袖の天端を標高で与える。
- 既定では河道の中心線に直角（両岸に直角）。回転角・中心・天端標高・堤長を指定すれば、その値で置く。
- 4 近傍で水が漏れない厚さにしている。

## 扱わないこと

- 非平衡流砂（流砂が平衡に近づくまでの遅れ）
- 浮遊砂・ウォッシュロード
- 土石流（高濃度流）
