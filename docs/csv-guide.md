# 地形 CSV の作り方

地形は「横断・縦断の測量値」か「格子 CSV」で読み込めます。どの「ファイル」欄から選んでも、中身から種類を見分けて正しい欄に入れます。
文字コードは UTF-8（BOM の有無は問わない）と Shift_JIS のどちらでも読めます。`#` で始まる行と見出し行は読み飛ばします。区切りはカンマ・タブ・空白のどれでも構いません。

## 座標の決まり

| 記号 | 意味 |
| --- | --- |
| x | 流下方向の距離 [m]。下流へ向かって増える。読み込んだ後は最上流が 0 |
| s | 左岸からの横断方向の距離 [m]（横断 CSV） |
| y | 横断方向の座標 [m]。左岸側が大きい（x, y, z 形式） |
| z | 標高 [m]。基準は 1 つの地形の中でそろえる |

左岸・右岸は下流を向いて決めます。堰堤の位置は、読み込んだ地形の最上流を 0 とした距離です。

## 横断 CSV（x, s, z）

1 行に測点を 1 つ。同じ x の行が 1 つの断面です。1 断面に 3 点以上、断面は 2 つ以上必要です。

```csv
x,s,z
0,0,33.780
0,14,26.780
0,39,25.000
0,64,26.780
0,78,33.780
50,0,30.686
...
```

- 断面の両端は、洪水でも水が乗り越えない高さまで入れる。端より外側は「断面の外側の谷壁勾配」の斜面として作る。
- 左岸標の位置が断面ごとにずれていても、「断面のそろえ方」（既定は最深部をそろえる）で横の位置を合わせる。
- 断面の間は、最深部の左右を幅で正規化した比例配分で補間する。
- 谷の向きがほぼまっすぐな区間を前提にしている。大きく曲がる谷は格子 CSV で与える。

## 縦断 CSV（x, z）

最深河床高。省略できます。与えると、各断面の形はそのままで、最深部の高さだけをこの縦断形に合わせます。

```csv
x,z
0,25.000
10,24.074
20,23.407
...
```

## 格子 CSV

- **行列形式**：標高だけを表のように並べる。1 行目が左岸側、左の列が上流。格子間隔はページで指定する。
- **x, y, z 形式**：1 行に 1 点。格子間隔は座標から求める。

DEM から作るときは、計算区間を囲む長方形を谷の向きに合わせて切り出し、上流が左になるように回転してから書き出します。格子間隔は 1〜4 m 程度（格子数の上限は 40,000）。

読み込んだ地形では、各横断の最低点から「谷底とみなす高さ」までを侵食できる河床とします。

## 計算後の河床 CSV

「河床を CSV ファイルに保存」（Python 版の `bed_csv`）で書き出した CSV は、行列形式に次のコメント行を足したものです。読み込むと、堰堤と谷底の範囲も前と同じに戻ります。

```
# floorH=2.4
# dam x=76.25 H=3 b=37.5 ang=-4.328 y=75.704 zc=32.097 len=52.5 so=-0.6
# floor 000000111111111111110000000
```

| 行 | 意味 |
| --- | --- |
| `# floorH=` | 谷底とみなす高さ [m] |
| `# dam` | 堰堤 1 基。x 位置、H 堤高、b 水通し幅、ang 回転角 [°]、y 中心の y 座標、zc 天端標高、len 堤長、so 水通しの中心のずれ（m） |
| `# floor` | 谷底（侵食できるセル）の印。1 が谷底、0 が谷壁。行の並びは数値の行と同じ |

## 時間ごとの結果の CSV

計算中、出水の時刻で「記録の間隔」ごとに結果を残し、次の形で保存できます（Python 版は `--snap-every 分`）。

**縦長の CSV**（1 行が 1 つの時刻・1 つの移動床セル）

| 列 | 意味 |
| --- | --- |
| 時刻_分 | 出水の時刻（河床変動の時間軸） |
| x_m, y_m | セルの中心。x は上流端からの流下方向の距離、y は右岸側の端からの距離（左岸側が正） |
| 河床高_m, 河床変動量_m | 河床変動量は計算開始時の河床からの変化（＋が堆積） |
| 水深_m, 水位_m, 流速_m/s | 乾いたセルは水深 0、水位は空欄 |
| 表層平均粒径_mm | 交換層の平均粒径 |

**zip（Python 版はフォルダ）**

| ファイル | 内容 |
| --- | --- |
| 集計_時系列.csv | 時刻ごとの流量・流砂量・累計土砂量・堰堤ごとの堆砂量 |
| 縦断_時刻別.csv | 時刻別の縦断（谷底の最深河床高と平均河床高） |
| 河床高/河床高_XXX分.csv | その時刻の河床高（計算後の河床 CSV と同じ形式。読み込むとその時刻の河床から計算できる） |
| 河床変動量/河床変動量_XXX分.csv、水深/水深_XXX分.csv | 行列（1 行目が左岸側、左の列が上流） |

## 変換プログラム（tools/xs2grid.py）

```bash
python xs2grid.py --make-test                       # テスト CSV を書き出す
python xs2grid.py --xs 横断.csv --long 縦断.csv --dx 2 --align thalweg --out grid.csv
```

ページの「横断・縦断の測量値」と同じ方法で格子にします。
