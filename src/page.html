ハイドロ（水と土砂の供給）

基底流量（清水）に、三角形の土石流の波（ピーク流量は混合物の流量）を重ねて上流端から流します。流入する土石流の流速と水深は、「流入点より上流の勾配」での等流（高橋の抵抗則）から決めます。流砂モデルは自動で「土石流」になり、河床変動は加速しません。供給土砂の粒度は「粒径と河床材料」の「供給」の割合です。

1行に「時刻[分], 流量[m³/s], 土砂量[m³/s]」。土砂量は実質体積。3列目を省くと濃度から計算します。

支川は谷壁を切り込んだ水路として作り、計算区間の側方の端から流し込みます（谷壁の外側を約 40 m 広げます）。流量と供給土砂量は、本川（上流端）の値に比を掛け、遅れの分だけずらします。土石流の一波のときは、支川からも同じ形の土石流が入ります。勾配の急な支川から土砂が出ると、合流点に沖積錐ができ、流路の首振り（流れの向きが堆積で変わる）が起きます。数値で指定した地形でだけ使えます。

横ずれは下流を向いて左が正です。横ずれは点の間を滑らかな曲線で、川幅は直線でつなぎます。表の「川幅」を入れると、湾曲と一緒に狭窄部や拡幅部を作れます（空欄の行は飛ばし、1つも入れなければ上の「川幅」と「川幅を途中で変える」を使います）。川幅は中心線に直角に測ります。片岸だけを張り出させるときは、横ずれも同時にずらします（例：左岸だけ 10 m 狭めるなら、川幅を 10 m 減らし、横ずれを −5 m）。曲がりの角度は 50° 程度までにしてください。

支渓の扇状地（崖錐）：岸に頂点を置いた円錐を谷底に重ねます。流れを反対の岸へ押しやります。

位置 x [m]岸半径 [m]高さ [m]

澪筋は谷底の中を滑らかに蛇行する初期の低水路です。起伏は砂州と淵の大きさの凹凸です。どれも 0 にすると、平らな谷底（横断勾配だけ）に戻ります。谷壁の高さ 0 は、堰堤の高さから決めます。

横断の値（x, s, z）と縦断の値（x, z）から地形を作ります。x は流下方向の距離、s は左岸からの距離、z は標高 [m] です。縦断を与えると、各断面の最深部の高さをその縦断形に合わせます。横断を空にすると、断面は「数値で指定」の川幅・横断勾配の形になります。

新しい横断だけを読み込むと、縦断の欄には前の値が残ります。別の場所の地形に替えるときは、先に「欄を空にする」を押してください。

断面の間は、最深部の左右それぞれを幅で正規化して比例配分で補間します。最深部（澪筋）は断面の間でもつながります。

形式は2通りです。①行列：1行目が左岸側、左の列が上流、値は標高 [m]。②x, y, z の3列：x は流下方向、y は左岸側が正。区切りはカンマ・タブ・空白のどれでも構いません。

各横断の最低点から「谷底とみなす高さ」までを侵食できる河床とし、それより高い所は侵食しない斜面として扱います。

透過型（スリット・鋼製）の設定と閉塞

形式：不透過（従来）、スリット（幅 l の切り欠き 1 本）、複数スリット（幅 l を柱の幅 w で開口数だけ並べる）、鋼製格子型（縦・横の部材の純間隔 l）、鋼製スリット型（縦の部材だけ、純間隔 l）。鋼製は水通しの全幅が開口です。開口の底は堤の基礎の高さです。

計算方法：開口のセルは開口の底の高さの河床とし、水は多孔板の損失係数（Idelchik）ζ = {(1 + 0.707√(1−φ) − φ)/φ}² の損失水頭 ζV²/2g を受けて通ります。φ は開口率（鋼製格子型 {l/(l+w)}²、鋼製スリット型 l/(l+w)、スリットは開口幅 ÷ セル幅）。天端より上を流れる分は損失を受けません。土砂は開口率 l/(l+w) の割合で通り、粒径 d ≥ l/α の礫は通れずに手前に堆積します（粒径別のふるい分け）。

閉塞：開口のすぐ上流の流れの土砂濃度（流砂量 ÷ 流量）が「閉塞が起きる土砂濃度」以上で、流れている土砂の d95 に対して l ≤ β d95 のとき閉塞し、以後は不透過型として働きます（開口は水だけが少し通る）。β の既定 1.5 は土石流対策技術指針（案）（建設省 2000）の「純間隔は最大礫径の 1.5 倍以下」、2016 年の土石流・流木対策設計技術指針では 1.0 倍です。濃度のしきい値は本プログラムの仮定で、掃流（濃度が低い）では閉塞せず、土石流で閉塞する、という観察に合わせています。

各堰堤の上流を、天端から「元の勾配 × 比」の勾配で土砂を満たした状態から始めます。比 0.5 は計画堆砂勾配を元河床勾配の 1/2 とする慣用の値です。堆砂量の表と河床変動量は、この満砂の状態からの変化です。

流砂モデル・側岸侵食

土石流（高橋 2007。Kanako 2D と同じ形の式）：混合物の水深 h、土砂濃度 C で計算します。侵食（C < C∞）i = δe (C∞ − C)/(C* − C∞)·q/d、堆積（C ≥ C∞）i = δd (C∞ − C)/C*·V。平衡濃度 C∞ は水面勾配 tanθ で、tanθ > 0.138 は石礫型 ρ tanθ/{(σ−ρ)(tanφ − tanθ)}、0.03〜0.138 は乱流型（その 2 乗の 6.7 倍）、0.03 以下は掃流の式。抵抗は石礫型（C ≥ 0.4C*）τ/ρ_T = d²u|V|/{8h²(C + (1−C)ρ/σ)((C*/C)^(1/3) − 1)²}、乱流型 d²u|V|/(0.49h²)、C < 0.01 は Manning 式です。適用条件と仮定：代表粒径 d は流れている土砂（なければ河床表層）の平均粒径で、粒径別の挙動（土石流内の分級）は扱いません。抵抗は Manning 式の値を下限にし（相対水深の大きい乱流型で抵抗が小さくなりすぎないように）、堆積速度の流速には下限 0.1 m/s を設けています（止まりかけの流れでも堆積させるため）。これらは本プログラムの仮定です。δe = 0.0007、δd = 0.05 は Kanako などで使われる値です。

i_k = f_bk·δe(C∞−C)/C*·|u*−u*ck|（侵食）、f_0k·δd(C∞−C)/C*·|u*−u*ck|（堆積）。流れの中の土砂を運び、その場で平衡濃度 C∞ との差だけ侵食・堆積させます（非平衡）。高橋・里深（1999）は δe = δd = 0.6、水深 5 mm 以下で δe = 1.2・δd = 6.0（倍率 2 と 10）としています。水際とみなす水深の自動値は平均粒径の 2.5 倍です（同論文の 5 mm／2 mm の比）。適用条件：δe、δd と水際の倍率は水路実験に合わせた値です。現地の規模へは、水際の水深を粒径との比で移しています（本プログラムの仮定）。掃流砂の式なので、浮遊砂・土石流の濃度では使えません。

水に浸かったセルでは、堆積層（侵食の下限より上）の空隙が満ちるまで、単位動水勾配で透水係数 k の速さで浸透します。堆積層の中の水は Darcy 則（Dupuit 近似）で水頭の低い方へ流れ、空隙からあふれた分は地表へ湧き出します。k は指定しなければ交換層の粒度から Kozeny–Carman 式 k = (g/ν)·n³/(1−n)²·d_h²/180（d_h は調和平均径）で求め、上限で頭打ちにします。土石流では間隙の水が抜けると濃度が上がり、堆積が進みます（扇状地での伏没・停止）。適用条件：鉛直方向の浸透は単位動水勾配（地下水面より上は不飽和）、水平方向は Dupuit 近似。礫が粗いと Darcy 則の範囲を超えるため、上限で抑えています。初期の地下水は、水に浸かったセルは飽和、乾いたセルは飽和度 s0 とします。

谷壁のうち、谷底から「侵食できる高さ」までを段丘・崖錐の土砂とし、削れるようにします（0 なら谷壁は固定床）。斜面は、水に浸かっていれば水中の安息角、乾いていれば陸上の安息角を超えた所で崩れます。水際の濡れたセルが削られると、その一部を隣の乾いた側岸から削ります（0 で使わない）。

長谷川の崩落モデル（長谷川 1983、長田ら 1996 式17）：水際の乾いた側岸は、根元の洗掘が進むまで立ったままです。側岸の位置の水面から水中安息角で下る線を引き、線より下の洗掘量 B が線より上の土塊 A に達したとき、A が一度に崩れて B を埋め戻します。崩落限界幅 ΔBc は 1 セル（格子幅）です。適用条件：長田らの検証は、粘着力のない砂（粒径 0.7〜1.4 mm）、勾配 1/100〜1/466、側岸の高さ 4〜7 cm の水路実験で、掃流砂が主で変化がゆるやかな場合です。崩れる周期が計算時間より十分短く、崩落土砂が埋め戻す範囲の河床変動が正しく計算できることが前提です。蛇行頂部の下流のように水際で流砂の非平衡性が強い所では侵食量が過小になったと報告されています（非平衡の流砂と合わせると改善が見込まれます）。粘着性の土、植生の根、引張り亀裂による崩落は扱いません。

湾曲部のらせん流（2次流）。流線の曲率 1/r を流速分布から求めます（3×3 で 2 回平滑化）。流砂の向き：河床付近の流速の横断成分 u_nb = N*·(h/r)·u_sb（長田ら 1996 式14、N* = 11.5）を長谷川式の横断方向流砂に加えます。分散項：Kalkwijk・de Vriend（1980）の流速分布の仮定から、主流の運動量を外岸へ運ぶ項（式19〜23）を運動方程式に加えます。流速の最大が外岸側へ寄ります。適用条件：曲率が弱い（h/r ≪ 1）こと、2次流が十分に発達していること（湾曲の入口での発達の遅れは扱いません）、流速分布が対数則に近いこと。そのため h/r を上限値で頭打ちにし、k_sn の近似式は √g/(κC) ≤ 0.4 の範囲で使います。長田らの検証は、勾配 1/400 の一様湾曲水路（砂、掃流砂が主）です。網状に分かれた流れや急勾配の渓流では、曲率は格子規模のばらつきを含むので、結果は定性的な目安です。

動かない巨礫を、水みち（初期の澪筋。なければ谷底）の両岸に間隔ごとに置きます。そのセルは侵食も堆積もしません。高橋・里深・奥村（1996）の水路実験では、間隔 L が水みち幅 B の 9/4 倍より狭いと水みちの拡幅・分裂が抑えられ、流路が固定されました。適用条件：水路実験から得た目安で、巨礫が流れで動かないことが前提です。巨礫の大きさは格子幅で決まり、実際の礫の大きさは表せません。

モデルの説明と参考文献

流れ

平面2次元浅水流方程式（保存形）を、セル中心の有限体積法で解きます。数値流束は HLL 近似リーマン解法、河床勾配項は静水圧再構築（Audusse ら 2004、Chen・Noelle 2017 の形）で扱います。水深 h と水位 η を minmod 制限付きで区分線形に再構築するので、静水と等流の両方を厳密に保ちます。抵抗は Manning 則です。堰堤の越流、跳水、乾湿の境界をそのまま計算できます。

流砂と河床変動

  • 粒径階ごとの掃流砂量は芦田・道上式。有効摩擦速度は対数則から求めます。
  • 平均粒径の限界掃流力は次の3通りから選べます。
    • 芦田・高橋・水山（1978）の式(24)：τ*c = 0.04×10^(1.72 i)。i は各セルの流れの向きの河床勾配で、0〜0.2 に制限します。
    • 岩垣式（1956）：粒径から u*c を求めます。原式は σ/ρ = 2.65 の値なので、(σ/ρ − 1)/1.65 を掛けて補正します。勾配の効果は入りません。
    • 一定値
  • 粒径別の限界掃流力は次の2通りから選べます。
    • 芦田・高橋・水山の実験結果：混合砂礫では、各粒径の限界掃流力（次元のある値）が平均粒径の値とほぼ等しくなります。つまり u*ci = u*cm です。この結果は d/dm ≥ 0.4 で得られたものです。d/dm < 0.4 でも同じ値としています。同論文の実験では、この範囲の細粒はさらに動きにくくなっていますが、式が示されていないためです。注意：混合粒径の芦田・道上式は q_bi = 17 f_i u*e³/(sg)·(1 − u*ci²/u*²)(1 − u*ci/u*) で、粒径 d_i は約分されて消えます。粒径による動きやすさの違いは u*ci だけから生じるので、この設定ではどの粒径も河床の含有率どおりに動き、細粒の選択的な流出や粗粒化（アーマー化）は起きません。
    • Egiazaroff 式の芦田・道上修正（既定）：d/dm ≥ 0.4 では u*ci²/u*cm² = {log19/log(19 d/dm)}²·(d/dm)、d/dm < 0.4 では τ*ci = 0.85 τ*cm·dm/di です。細粒は動きやすく粗粒は動きにくくなり、細粒の選択的な流出と表層の粗粒化が起きます。
  • 流砂の向きは流速の向きに、河床勾配による重力の効果を加えます。係数は長谷川の横断方向流砂量式の形 √(τ*c/(μs μk τ*)) を使い、勾配方向の拡散として等方的に与えています。
  • 粒度は交換層（平野）と多層の堆積層で追跡します。粗粒化（アーマー化）と、堆積した土砂の再侵食時の粒度を表現できます。
  • 安息角を超えた斜面は崩落させます。水に浸かった斜面は水中の安息角（既定 30°、高橋・里深・奥村 1996）、乾いた斜面は陸上の安息角（既定 50°）で判定します。重力項と合わせて、側岸侵食と流路の移動を表します。
  • 側岸侵食の拡張：谷壁の下部を侵食できる段丘・崖錐とする設定、水際の濡れたセルの侵食の一部を隣の乾いた側岸から削る設定（Delft3D の dry-cell erosion と同じ考え方）、動かない巨礫で流路を固定する設定（高橋・里深・奥村 1996）、長谷川の崩落モデル（側岸は根元の洗掘が溜まってから一度に崩れる。長田ら 1996）を選べます。
  • 湾曲部の2次流（長田ら 1996）：流線の曲率から、河床付近の流れを内岸へ向ける効果（流砂の向き）と、主流の運動量を外岸へ運ぶ分散項（Kalkwijk・de Vriend 1980）を加えられます。どちらも弱い曲率を前提とする式です。
  • 勾配の屈折：「勾配を途中で変える」の表で、位置ごとに勾配を変えた折れ線の縦断にできます（多段の屈折も可）。
  • 透過型堰堤：スリット（単・複）、鋼製格子型、鋼製スリット型を選べます。開口は多孔板の損失係数（Idelchik）で水を通し、粒径 d ≥ l/α の礫は通しません。閉塞は、流れの土砂濃度と l ≤ β d95（土石流対策技術指針（案）2000 の β = 1.5）で判定し、閉塞後は不透過型として働きます。
  • 土石流の一波：高橋（2007）の式（Kanako 2D と同じ形）。混合物の水深と土砂濃度で、侵食・堆積速度式、水面勾配による平衡濃度（石礫型・乱流型・掃流）、石礫型・乱流型・Manning の抵抗則を使います。δe = 0.0007、δd = 0.05。
  • 支川の合流：谷壁を切り込んだ支川の水路から流量と土砂を流し込みます。急な支川の土砂は合流点に沖積錐をつくり、堆積で流れの向きが変わる（首振り）様子を計算できます。
  • 伏流：水に浸かった堆積層へ単位動水勾配で浸透し、堆積層の中を Darcy 則（Dupuit 近似）で流れ、空隙からあふれると湧き出します。透水係数は Kozeny–Carman 式で粒度から求めます（上限あり）。
  • 流砂量は、平衡流砂量（芦田・道上式）のほかに、高橋・里深（1999）と高橋ら（1998）の侵食・堆積速度式（非平衡）でも計算できます。流れの中の粒径別土砂濃度を運び、平衡濃度との差で侵食・堆積させます。水際の浅い所では係数を割り増して、水際の掃流力の過小評価を補います。
  • 堰堤は1セル幅の固定床です。天端、水通し、袖部を標高で与えます。固定床への段上がりが水深の半分を超える間は、掃流砂を通しません。

モデル渓流（数値で指定する地形）

谷底は、縦断勾配の面に、澪筋（初期の低水路）へ向かう横断勾配、澪筋の掘り込み、砂州と淵の大きさの起伏を重ねて作ります。左右の岸線は別々に不規則にずらします。谷壁は岸から「谷壁の勾配」で立ち上がる侵食しない斜面で、支渓の扇状地は岸に頂点を置いた円錐として重ねます。扇状地のうち谷底に乗った部分は侵食できます。用意した2つのモデル渓流は、早月川の床固工群と南股入の堰堤群の航空写真を参考にした架空の地形で、実際の川の測量値ではありません。樹木は表示だけのもので、計算には入りません。

網状流路・砂州

流路の分岐や砂州は式として与えていません。初期河床の小さな凹凸から、流れの集中、洗掘、側岸侵食、堆積の繰り返しで自然に生じます。この種の平面2次元モデルで網状流路を再現した例に里深・高橋（1998）があります。本プログラムは同じ種類のモデルですが、同論文の式や係数をそのまま再現したものではありません。

適用範囲と注意

  • 掃流砂が主体の領域が対象です（目安として勾配 1/10 より緩い区間）。土石流、掃流状集合流動、浮遊砂、ウォッシュロード、二次流は扱いません。
  • Manning 則でフルード数が 1.5 を大きく超えると転波列が出ます。急勾配では n を大きめにしてください。
  • 堰堤直下に水叩きや副堰堤はありません。直下は侵食可能深まで洗掘されます。
  • 河床変動の加速係数は流量の時間軸を縮めます。大きすぎると出水の伝播が遅れて見えます。
  • 供給土砂が輸送能力を超えると、上流端に堆積します。
  • 実験や現地との検証はしていません。定量的に使う前に検証が必要です。

確認した項目

静水の保持（流速 10⁻¹⁴ 以下）、Manning の等流水深との一致（勾配 1/50〜1/10 で誤差 0.01% 未満）、水と土砂の体積収支（丸め誤差の範囲）。
